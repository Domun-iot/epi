# Logo sources

- Android, Windows 11, Linux, Debian, Ubuntu, Linux Mint, Chrome, Firefox, Safari: Devicon v2.17.0, https://github.com/devicons/devicon/tree/v2.17.0/icons (MIT; DEVICON-LICENSE).
- Edge: Simple Icons v11; Open Source Initiative, Opera and GitHub: Simple Icons v14, https://github.com/simple-icons/simple-icons (CC0; SIMPLE-ICONS-LICENSE).
- Generic web, download, terminal, server, code and archive icons: project SVG artwork.
- Google Play (`../google-play.svg`): Simple Icons v14.0.0, `icons/googleplay.svg` (CC0; SIMPLE-ICONS-LICENSE), split into four coloured paths.

Logos identify supported platforms; trademarks remain with their respective owners.
